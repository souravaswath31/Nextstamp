## 2. How to answer visa questions on Reddit and forums

- Read the community's self-promotion rule first and message the moderators before you post anything with a link.
- Answer the question properly in the comment, with the official source link. Mention NextStamp only if it helps, and say it is yours.
- Never paste a competitor's list. Their counts disagree; link to the official page instead.
- Reply template: "For {passport} to {destination}, the {authority} page says {one-sentence rule} (checked {date}). It applies to {condition}. Worth confirming right before you book because {end date or caveat if any}. Full detail with the source: {link}. (I run NextStamp, the site that link goes to.)"
